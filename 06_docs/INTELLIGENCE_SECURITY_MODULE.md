### 1. **Inteligencia de Ciberseguridad (CyberIntel)**

#### OSINT (Open Source Intelligence)
```
Intelligence Gathering │ Pattern Analysis │ Risk Assessment
─────────────────────┼──────────────────┼─────────────────
• Social media scan  │ • Threat patterns │ • Exposure score
• Domain analysis    │ • Attack chains  │ • Vulnerability rank
• Email tracing      │ • TTPs detection │ • Compromise level
• Tech stack detect  │ • Anomalies      │ • Priority matrix
• Geolocation        │ • Relationships  │ • Action items
```

**Ejemplo de flujo**:
```
Usuario: "Analiza a la empresa X"
     ↓
ASI activado
     ↓
OSINT Pipeline:
  1. Buscar dominios registrados (WHOIS, Shodan)
  2. Extraer tecnologías usadas (Wappalyzer equivalente)
  3. Analizar empleados públicos en LinkedIn
  4. Monitorear menciones en redes sociales
  5. Verificar si credenciales están comprometidas
  6. Evaluar exposición de datos
  7. Generar reporte de riesgo
     ↓
Resultado: "Riesgo alto: 3 empleados con creds comprometidas,
            AWS mal configurado, 0-day conocido en stack"
```

## 📚 Casos de Uso Reales

### Caso 1: Auditoría de Seguridad Interna
```
Usuario: "KALMIYA, analiza la seguridad de mi servidor web"

ASI Analysis:
├── Escaneo de puertos y servicios
├── Búsqueda de configuraciones inseguras
├── Análisis de certificados SSL/TLS
├── Revisión de encabezados HTTP
├── Evaluación de autenticación
├── Análisis de inyecciones posibles
└── Reporte con score de severidad

Resultado: "Score 72/100. 3 riesgos altos, 7 medios. 
            Recomendaciones: Actualizar OpenSSL, implementar 
            CORS, habilitar HSTS, auditar permisos de BD."
```

### Caso 2: Análisis de Breach
```
Usuario: "Encontré logs raros en mi servidor. ¿Qué pasó?"

ASI Analysis:
├── Procesa logs con IA
├── Identifica primer acceso (fecha/IP/método)
├── Mapea progresión del ataque
├── Detecta datos accedidos
├── Identifica técnicas usadas (TTPs)
├── Atribuye probable grupo/actor
└── Propone acciones inmediatas

Resultado: "Ataque APT-28. Entrada: SSH bruteforce. 
            Propagación: escalada de privilegios. 
            Exfiltración: 2.3GB de BD. Fecha: 2026-08-01. 
            Acciones: Change creds, parchear, investigar..."
```

### Caso 3: Inteligencia de Amenazas
```
Usuario: "¿Qué amenazas afectan a sistemas Java en 2026?"

ASI Analysis:
├── Busca CVEs activos para Java
├── Analiza campañas conocidas
├── Predice próximas vulnerabilidades
├── Evalúa probabilidad de explotación
├── Mapea actores conocidos
└── Propone defensa proactiva

Resultado: "3 CVEs críticos activos. Grupo APT-X targeting
            Java apps. Predicción: Log4Shell-style en Q4.
            Recomendación: Audit libs, update Java 21+,
            implement WAF rules."
```

### Caso 4: Análisis de Privacidad
```
Usuario: "¿Mi app cumple GDPR?"

ASI Analysis:
├── Analiza qué datos recolecta
├── Verifica consentimiento
├── Evalúa almacenamiento/retención
├── Revisa terceros
├── Verifica derecho al olvido
└── Genera compliance report

Resultado: "87% GDPR compliant. Gaps: Política de 
            privacidad incompleta, sin DPA firmados, 
            retención > 3 años sin justificación. 
            Prioritario: Arreglar en 30 días."
```
