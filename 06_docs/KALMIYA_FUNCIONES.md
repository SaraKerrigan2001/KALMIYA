## 📚 GUÍA DE IMPORTACIÓN

Para usar cualquier módulo en tus scripts:

```python
# Importar un módulo individual
from modules import TODOManager, PomodoroTimer, ExpenseTracker

# O importar la clase específica
from modules.todo_manager import TODOManager
from modules.health_tracker import HealthTracker

# Crear instancia
todo_mgr = TODOManager()
todo_mgr.add_todo('task1', 'Mi primera tarea', priority='high')
```
