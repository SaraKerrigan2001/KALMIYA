# 01_systems — Sistema Principal de KALMIYA

[[INDEX|← Índice]] | [[README|📄 README Principal]] | [[06_docs/ROOT_STRUCTURE|🗂️ Estructura]]

Esta carpeta concentra los componentes centrales del asistente: el núcleo del sistema, la bóveda personal y la base de conocimiento integrada.

## Contenido

- **KALMIYA/**: bóveda personal, bienvenida y recursos del entorno de uso diario.
- **KALMIYA_System/**: motor principal, módulos, lógica de chat, memoria y capacidades avanzadas.
- **LLM_Wiki/**: base de conocimiento y esquema de información para la IA.
- **RAPTOR/**: framework de seguridad autónomo (submódulo Git)

## Uso recomendado

- Mantén el código funcional y modular en KALMIYA_System.
- Usa la bóveda KALMIYA para notas, enlaces y contexto personal.
- Actualiza LLM_Wiki cuando agregues conocimiento útil o nuevas reglas de comportamiento.
