# 📚 wiki/ - Conocimiento Depurado

Aquí se almacena el conocimiento procesado, validado y enlazado.

## Estructura

Este directorio contiene notas de Markdown enlazadas ([[wiki-links]]) que representan tu conocimiento consolidado.

### Tipos de Notas

- **Conceptos**: Definiciones y explicaciones
- **Decisiones**: Decisiones tomadas y razones
- **Procesos**: Flujos y procedimientos
- **Aprendizajes**: Lecciones y insights
- **Proyectos**: Estado de proyectos activos
- **Personas**: Perfiles de contactos importantes
- **Recursos**: Enlaces útiles y referencias

## Gestión de Wiki

- Crear una nota por concepto/decisión
- Usar `[[wiki-links]]` para conectar
- Mantener índice actualizado
- Revisar mensualmente por obsolescencia
- Usar tags para categorización: `#proyecto #decisión #aprendizaje`
