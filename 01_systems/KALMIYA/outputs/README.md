# 📂 outputs/ - Resultados y Entregas

Aquí se almacenan los resultados procesados y entregas de JARVIS.

## Estructura

### `metricas/`
- Análisis de métricas procesadas
- Formato: Markdown + JSON
- Archivos: `reporte_YYYY-MM-DD.md`
- Generado por: Skill "Métricas"

### `bandeja/`
- Resumen matutino compilado
- Formato: Markdown + Audio (MP3)
- Archivos: `bandeja_YYYY-MM-DD.md`
- Generado por: Skill "Bandeja" (7:00 AM)

### `plan/`
- Plan diario con 3 prioridades
- Formato: Markdown estructurado
- Archivos: `plan_YYYY-MM-DD.md`
- Generado por: Skill "Plan" (9:00 AM)

### `tendencias/`
- Análisis de tendencias y patrones
- Formato: Markdown + Gráficos (JSON)
- Archivos: `tendencias_YYYY-MM-DD.md`
- Generado por: Skill "Tendencias" (2:00 PM)

### `seguridad/`
- Reportes de auditoría y seguridad
- Formato: Markdown + logs
- Archivos: `audit_YYYY-MM-DD.md`
- Generado por: Skill "Seguridad" (14:45)

### `inteligencia/`
- Análisis profundos e insights
- Formato: Markdown con fuentes
- Archivos: `insight_TIMESTAMP.md`
- Generado por: Skill "Inteligencia" (bajo demanda)
