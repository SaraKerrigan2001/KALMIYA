## Descripción
El skill **Plan** identifica las 3 cosas más importantes que debes hacer hoy para avanzar hacia tus objetivos. Combina:
- Compromisos del calendario
- Métricas y tendencias
- Retroalimentación del trabajo anterior
- Impacto potencial

## Qué Hace
- 🎯 Selecciona 3 prioridades del día
- ⏰ Estima tiempo de cada una
- 📋 Organiza por importancia
- 📝 Escribe 3 prioridades en tu bóveda
- 📊 Rastrea progreso durante el día

## Parámetros de Activación
```python
"¿cuáles son mis 3 prioridades?"
"plan de hoy"
"dame el plan"
"enfócame en lo importante"
"establece prioridades"
```

## Flujo de Trabajo
1. **Consulta** → Bandeja, métricas, tendencias, calendario
2. **Filtra** → Eventos críticos, deadlines, impacto
3. **Selecciona** → 3 prioridades máximo
4. **Estima** → Tiempo requerido, recursos
5. **Escribe** → Nota estructurada en bóveda

## Entrada
- Calendario: Eventos hoy
- Bandeja: Resumen matutino
- Métricas: Estado actual
- Tendencias: Oportunidades/riesgos
- Objetivos: Metas semanales/mensuales

## Salida
```
### 📌 PLAN DE HOY
**2026-08-12**

#### ⚡ Prioridad 1: Reunión con Producto
- **Tiempo**: 09:00 - 09:45 (45 min)
- **Ubicación**: Zoom
- **Preparación**: Revisar deck de métricas
- **Objetivo**: Alineamiento Q4
- **Impacto**: 🔴 Alto

#### 📊 Prioridad 2: Presentar Métricas
- **Tiempo**: 14:00 - 15:00 (60 min)
- **Ubicación**: Sala ejecutiva
- **Preparación**: Hecho ✓
- **Objetivo**: Comunicar progreso
- **Impacto**: 🟡 Medio

#### 🔍 Prioridad 3: Code Review RAPTOR
- **Tiempo**: Flexible (90 min)
- **Tickets**: 3 PRs pendientes
- **Enfoque**: Security > Performance
- **Objetivo**: Mantener calidad
- **Impacto**: 🟢 Bajo

#### 📈 Métrica de Éxito Hoy
✓ Completar las 3 prioridades = 100% productividad
→ Target: Realizar antes de 18:00
```
