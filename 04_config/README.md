# 04_config — Configuración y Empaquetado

[[INDEX|← Índice]] | [[README|📄 README Principal]] | [[06_docs/ROOT_STRUCTURE|🗂️ Estructura]]

Esta carpeta centraliza la configuración del proyecto para Python y la distribución del paquete.

## Archivos clave

- **pyproject.toml**: configuración moderna del proyecto.
- **requirements.txt**: dependencias de instalación.
- **setup.cfg**: configuración adicional y metadatos.
- **kalmiya.egg-info/**: información generada por empaquetado.

## Recomendaciones

- Actualiza requirements.txt cuando añadas dependencias nuevas.
- Mantén pyproject.toml coherente con las herramientas de desarrollo.
