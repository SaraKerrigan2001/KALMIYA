💻 Ejemplos de Componentes

Sistema SENA de Gestión de Bienes

📋 Cómo usar estos ejemplos

  1. Haz clic en cualquier tarjeta para copiar el nombre del archivo
  2. Abre el archivo correspondiente en la carpeta examples/
  3. Copia todo el contenido del archivo
  4. Reemplaza el contenido de src/App.jsx con lo copiado
  5. Guarda y el navegador se recargará automáticamente
