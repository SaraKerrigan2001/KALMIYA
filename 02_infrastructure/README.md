# 02_infrastructure — Infraestructura y Entorno

[[INDEX|← Índice]] | [[README|📄 README Principal]] | [[06_docs/ROOT_STRUCTURE|🗂️ Estructura]]

Esta carpeta contiene los recursos que sostienen la ejecución local de KALMIYA: entorno virtual, dependencias, scripts auxiliares y áreas de trabajo temporal.

## Contenido

- **Lib/**: librerías del entorno virtual y dependencias instaladas.
- **Scripts/**: utilidades de automatización y soporte operativo.
- **reports/**: reportes, auditorías y salidas de diagnóstico.
- **scratch/**: pruebas rápidas, experimentos y archivos temporales.

## Recomendaciones

- No guardes secretos ni claves en esta carpeta.
- Usa scratch para pruebas rápidas y luego limpia lo que ya no necesites.
