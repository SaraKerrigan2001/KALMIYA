# 05_tests — Pruebas, auditorías y validación

Esta carpeta reúne pruebas automáticas, comprobaciones del sistema y utilidades de revisión.

## Qué encontrarás aquí

- Pruebas de módulos, cerebro, memoria, personalidad y capacidades avanzadas.
- Scripts de auditoría para verificar redes, dispositivos y bases de datos.
- Herramientas de diagnóstico para revisar logs y comportamiento del sistema.

## Cómo usarlo

- Ejecuta pytest sobre un archivo concreto o sobre la carpeta completa.
- Usa los scripts de auditoría para comprobar estado del sistema.
- Mantén las pruebas alineadas con las funciones nuevas que agregues.
